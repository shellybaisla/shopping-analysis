
# Customer Behavior Analytics Dashboard

A dynamic, interactive data analysis project built to explore customer shopping patterns — focusing on revenue trends, category performance, demographic insights, and subscription behavior.

## Project Overview
This is an end-to-end data analysis project on 3,900 customer transactions from a retail shopping platform. The project covers the full data pipeline — from raw data exploration and cleaning in Python (Pandas), business question analysis in MySQL, to an interactive visual dashboard in Power BI.

## Short Description / Purpose
The Customer Behavior Analytics Dashboard is a visually engaging and analytical report designed to help businesses understand their customers better. It explores purchasing patterns across demographics, product categories, seasons, and payment behaviors — enabling data-driven decisions around marketing, inventory, and customer retention.
This project is intended for:

📊 Data analysts exploring retail behavior
🏪 Business stakeholders tracking revenue trends
🎓 Aspiring analysts building portfolio projects


##  Tools & Technologies Used
- **Python (Pandas)** - Data exploration, cleaning & feature engineering
- **MYSQL** - Business question analysis via SQL queries
- **Power BI** - Interactive dashboard & data visualization
- **CSV / Excel** - Raw data storage & import

## Dataset
Source: Kaggle — Customer Shopping Behavior Dataset
Rows: 3,900 customer records
Columns: 18 features

## Key Insights
- Most purchases are from Clothing category
- Weekly frequency customers spend the most
- Spring season has highest purchases
- PayPal and Credit Card are most used payment methods

## DATA CLEANING
- Removed null values
- Checked duplicates
- Standardized dataset

## Conclusion
The project successfully identified customer trends and business insights useful for retail decision-making.
